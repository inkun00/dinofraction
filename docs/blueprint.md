# **App Name**: Dino Fractions

## Core Features:

- Dinosaur Evolution: The player controls a dinosaur that evolves as the player scores points by answering fraction problems.
- Animated Backgrounds: A game environment featuring animated backgrounds, including ground, grass, trees, and clouds to give the player a sense of progression.
- In-Game HUD: In-game HUD displaying the player's score, lives, and a timer.
- Adaptive Problem Generation: A fraction problem generation module that dynamically adjusts difficulty based on the player's current score, covering addition and subtraction problems.
- Collision Detection: When the dinosaur jumps into the problem, determine if the player 'answered' the question correctly or incorrectly.
- Personalized feedback (tool): After completing a game session, the AI will provide customized feedback regarding the type of fractions that the user struggles with. The analysis will be summarized as a recommendation on the analysis screen.
- Account system: Users are given the option to either log into their account or to continue in "guest mode" with an anonymous account.

## Style Guidelines:

- Primary color: Sky blue (#87CEEB) to evoke a sense of the open sky and playful learning environment.
- Background color: Very light blue (#E0F2F7) to maintain a bright and airy feel without overwhelming the user.
- Accent color: Coral (#FF7F50) to highlight important elements and call-to-action buttons, providing a warm, inviting contrast.
- Body and headline font: 'Jua', a handwritten font, for headlines and body text, lending a childlike feel
- Use clean and simple icons for UI elements, sourced from a consistent style.
- Maintain a balanced layout with clear visual hierarchy, ensuring key information and interactive elements are easily accessible.
- Implement subtle animations for transitions and feedback, enhancing the user experience without causing distraction.
